Exercício 1.2 O que é um Tipo Abstrato de Dados – TAD? 
R: TAD é um conjunto de dados que devem ser armazenados, e por um grupo de operadores que podem ser aplicados para a manipulação desses dados
Como os dados armazenados em um TAD devem ser manipulados?
R: Os dados devem ser manipulados exclusivamente através dos operadores
Em que momento um TAD deve ser identificado e definido?
R: na fase de Projeto do Software

Exercício 2.21 O que significa Alocação Sequencial de Memória
para um conjunto de elementos?
R: Os elementos ficam, necessariamente, em posições de memória adjacentes uma a outras, ou seja, os elementos ficam em sequência.
